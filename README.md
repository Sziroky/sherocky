# Sherocky: strona zespołu

Wersja podglądowa (niepubliczna: `noindex`, `robots.txt` blokuje indeksowanie).

- `site/`: strona (Astro). `cd site && npm install && npm run dev`
- `site/src/data/`: oferta i ceny (`offer.json`), koncerty (`concerts.json`), skład (`band.json`)
- `assets/brand/`: logo w SVG
- `tools/`: skrypty (logo, preset zdjęć)

Deploy podglądu: GitHub Pages (push na `main`).
